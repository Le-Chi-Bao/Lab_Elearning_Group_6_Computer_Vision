# Computer Vision - Lab 2

Repository lưu trữ các bài thực hành môn Thị giác máy tính (Computer Vision).

## Cấu trúc thư mục

- `lab_2_phan_1.ipynb`: Bài thực hành Lab 2 - Phần 1
- `lab_2_phan_2.ipynb`: Bài thực hành Lab 2 - Phần 2
- `input.jpg`: Ảnh mẫu sử dụng trong bài thực hành

## Yêu cầu môi trường

- Python >= 3.8
- OpenCV (`opencv-python`)
- NumPy
- Matplotlib
- scikit-image
